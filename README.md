# Consultorios Buenos Aires — turnos y pagos online

Demo de sistema de turnos y pago online para Consultorios Buenos Aires (Longchamps).
Hecho por [Vigolo Web Studio](https://vigolowebstudio.com).

- `index.html`: reserva de turnos para pacientes
- `admin.html`: panel de administración (clave de prueba: 1234)
- `data.js`: todo el contenido editable (especialidades, precios, horarios). Lo marcado `PENDIENTE CLIENTE` es dato de ejemplo.

HTML + CSS + JS vanilla, sin build. Los turnos se guardan en el navegador (demo); el pago con Mercado Pago es simulado.
